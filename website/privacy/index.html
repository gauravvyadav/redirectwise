[ LEGAL COMPLIANCE & PRIVACY DISCLOSURE ]

Privacy Policy.

LAST UPDATED // DECEMBER 5, 2025

1. Core Privacy Architecture

RedirectWise ("we", "our", or "us") is architected around strict client-side isolation. Our browser extension executes 100% on your device with zero remote server communications, zero telemetry, and zero analytics trackers.

2. Information Processed Locally

The extension audits and stores the following technical metadata locally on your device only:

  • Visited URLs and their immediate HTTP redirect hops
  • HTTP response status codes (301, 302, 307, 308, etc.)
  • HTTP response headers (Server, Cache-Control, HSTS, CSP)
  • Hop latency and millisecond request timing
  • User preferences (such as dark mode toggle)
NOTE: No data is ever transmitted, synchronized, or stored on external cloud infrastructure.

3. Purpose of Local Data Processing

All collected data remains strictly within your browser's private local sandbox for:

  • Displaying real-time redirect hop chains in the extension popup and side panel
  • Maintaining your persistent redirect history log (up to 2,000 entries)
  • Generating client-side PDF and PNG export files upon your explicit user action
  • Persisting dark appearance settings

4. Data Storage & User Deletion

All records reside in your browser's chrome.storage.local partition. You can permanently wipe all records at any moment by using the "Clear All History" button in the Dashboard, or by uninstalling the extension.

5. Third-Party Services & Zero Telemetry

RedirectWise contains zero Google Analytics, zero telemetry SDKs, zero ads, and zero third-party trackers. No network requests are dispatched outside your active navigation context.

6. Browser Permission Justifications

webRequest
Captures HTTP response headers and status codes.
webNavigation
Detects client-side JS redirects and page transitions.
tabs
Associates redirect chains with active browser tabs.
storage
Persists history and preferences locally on-device.
